# AutiConnect

AutiConnect is a Final Year Project about continuous user learning and adaptive personalisation for autistic individuals. The initial demonstration will use synthetic users to show how an application can remember reviewed information, predict a response-format preference from feedback and adjust as preferences change.

The current milestone is **M0 · Repository discovery and design**. Application implementation, database migrations, training and evaluation are planned for later milestones.
